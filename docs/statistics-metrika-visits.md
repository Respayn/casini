# Тройной счёт визитов Метрики в Статистике

Для SEO-проекта Касини при сохранении Метрики всегда включает три отчёта переходов вместе: «Поисковые системы», «Поисковые запросы», «География». Галочек по отдельности в модалке нет.

Это один и тот же визит, только разрезанный по-разному: поисковик, фраза, город. Складывать три отчёта нельзя, иначе визит посчитается три раза.

В Word всё разделено: у каждого отчёта своя таблица и свои теги. Там ничего не суммируется.

В продукте «Статистика» визиты из Метрики ещё не подключены. В `app/Services/Statistics/StatisticsService.php` факт визитов пустой (`$visitsFact = null`). Колонки закрытия тоже получают пустой список визитов по дням.

Когда визиты подключим, для Статистики нужен один источник, а не сумма трёх отчётов. Кандидат: итог «Поисковые системы». Вопрос «включены только запросы или только география» закрыт: после сохранения пакет полный. Визиты или посетители - одна настройка `visits_metric` на весь блок «Переходы».
